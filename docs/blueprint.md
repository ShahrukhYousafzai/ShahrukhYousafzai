# **App Name**: PixelForge Portfolio

## Core Features:

- Interactive Game Showcase: Interactive game showcase with playable demos (where feasible) embedded directly on the page.
- AI Game Recommender: AI-powered tool to generate personalized game recommendations based on user preferences and portfolio analysis. Use of the tool determines what content the AI will present.
- Interactive Timeline: A dedicated 'About Me' section with interactive timeline of professional milestones.
- Contact Form: A contact form for potential clients or collaborators to directly reach out.
- External Profile Links: Links to external profiles on platforms like GitHub, Itch.io, and LinkedIn.
- Testimonials Section: A section showcasing testimonials or reviews from previous clients or collaborators.
- Tech Stack Overview: Clearly state the technologies and languages that were used on each project.

## Style Guidelines:

- Primary color: Electric blue (#7DF9FF) to evoke a futuristic and high-tech feel.
- Background color: Dark gray (#282828) to provide a dark, immersive backdrop.
- Accent color: Neon green (#39FF14) for highlights and interactive elements.
- Headline font: 'Space Grotesk' (sans-serif) for a techy, scientific feel.
- Body font: 'Inter' (sans-serif) for a clean, modern look and readability.
- Use glowing, minimalist icons representing various game development skills and technologies.
- A modular layout with clear sections for each portfolio piece, 'About Me', and contact information.
- Subtle animations and transitions to create a smooth and engaging user experience; for instance, parallax scrolling and hover effects on portfolio items.
